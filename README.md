## Getting Started

```shell
ni -D @proj-airi/unocss-preset-chromatic # from @antfu/ni, can be installed via `npm i -g @antfu/ni`
pnpm i -D @proj-airi/unocss-preset-chromatic
yarn i -D @proj-airi/unocss-preset-chromatic
npm i -D @proj-airi/unocss-preset-chromatic
```

```ts
// unocss.config.ts
import { presetChromatic } from '@proj-airi/unocss-preset-chromatic'
import { defineConfig } from 'unocss'

export default defineConfig({
  presets: [
    presetChromatic(),
  ],
})
```

### Color models

Shades are derived from a hue by a versioned color model, chosen with the `model` option (`v2` by default). A released version never changes its colors; an improved fit ships as a new version.

- `v2`: lightness, chroma and a small hue drift all vary smoothly with hue. They are fitted to the Tailwind CSS v4 palette, except around yellow, where the fit targets a share of the sRGB gamut so that light shades do not turn neon.
- `v1`: each shade has a fixed OKLCH lightness, and the chroma is `0.18 + 0.04 · cos(hue)` scaled per shade. This is the model of chromatic 1.x; pass `model: 'v1'` to keep those colors.

```ts
presetChromatic({
  baseHue: 220.25,
  colors: { primary: 0 },
  model: 'v1', // keep the colors of chromatic 1.x
})
```

```ts
import { chromaticColorFrom, themeFrom } from '@proj-airi/chromatic'

chromaticColorFrom(220.25, { shade: 500 }).toHex() // v2
chromaticColorFrom(220.25, { model: 'v1', shade: 500 }).toHex()
themeFrom(220.25, { accent: 180, primary: 0 }, { model: 'v1' })
```

With `v2`, the preset computes lightness and chroma from `--chromatic-hue` on `:root`. If you override `--chromatic-hue` on a subtree, the hue still rotates there, but lightness and chroma stay the ones of the root. `v1` already behaves like this for chroma.

To use the colors in your own CSS, `--at-apply` / `@apply` and `theme()` of `transformerDirectives` both work, e.g. `background: theme('colors.primary.400')` or `theme('colors.primary.400 / 50%')`. The preset adds an explicit opacity to `theme()` calls of its colors that have none, so they do not leave the opacity placeholder behind.

### Development

```bash
pnpm dev
```

The playground's chroma lab (`pnpm dev`, then open `/lab`) visualizes both models and runs the fit interactively. The `v2` coefficients are a least-squares fit of the Tailwind CSS v4 palette, generated by `scripts/fitted/`:

```bash
pnpm generate:fitted          # regenerate packages/chromatic/src/model-v2.ts
pnpm generate:fitted --check  # fail when the committed coefficients are out of date
```

### Build

```bash
pnpm build
```
